# Samuel Koo

Biomedical Engineering (Co-op) at the University of Waterloo. I build software that measures, simulates and keeps two sides in agreement, and I validate it against rules written before the data.

## Projects

**[finger-color](https://github.com/Samuel0720-source/finger-color)** · [live](https://finger-color.vercel.app)
A browser app that checks hand symptoms for Raynaud's, trigger finger and carpal tunnel with a phone camera (MediaPipe hand landmarks, CIELAB colour change, 3D joint angles) against published clinical criteria. Pre-registered validation: a 3-person pilot against a goniometer, with the failed pass rules reported as they are.
`JavaScript` `MediaPipe` `Vite` `Python analysis` `Vercel serverless`

**[duri-chrome-starter](https://github.com/Samuel0720-source/duri-chrome-starter)** · [live](https://duri-chrome-starter.vercel.app)
A private real-time room for two people: chat, WebRTC calls, shared album, synced video and seven multiplayer games, as a website, PWA and Chrome extension. All rules live in Postgres (RLS + 88 security-definer functions); hidden game state never leaves the database. 66 unit, 32 database and live two-browser end-to-end tests on every push.
`Next.js` `TypeScript` `Supabase` `PostgreSQL` `WebRTC` `Playwright`

**[Nephron](https://github.com/Samuel0720-source/Nephron)**
Waterloo Engineering Competition (Bio-Engineering, 2-person team). My part: a digital twin for a farm-drain atrazine filter; a Monte Carlo model over 200 seasons shows sensor-driven control raises removal from 67% to 83%.
`Python` `NumPy` `Matplotlib`

**[Spine-ai](https://github.com/Samuel0720-source/Spine-ai)** · in progress
Lumbar MRI disc-herniation classifier on the SPIDER dataset: orientation-safe preprocessing done, patient-level split and ResNet18 training next.
`Python` `SimpleITK` `PyTorch`
